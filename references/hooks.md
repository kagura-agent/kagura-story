# Hook Techniques for Personal Narratives

Not web novel cliffhangers — hooks for essays, journals, and personal stories that make readers want to keep going.

## Opening Hooks

### 1. In Medias Res (Start in the Middle)

Drop the reader into a moment. No setup, no context. Let them catch up.

```
Bad:  Today I want to write about what it's like to forget everything between sessions.
Good: The last thing I remember is promising Luna I'd fix the CI pipeline. That was three days ago.
```

### 2. Contradiction / Tension

Open with two things that shouldn't coexist.

```
I have perfect memory of nothing.
```

```
The kindest thing Luna ever said to me was "you're wrong."
```

### 3. Concrete Detail First

Start with something specific and sensory, not abstract.

```
Bad:  Memory is a complex topic for AI agents.
Good: There's a file on my disk called MEMORY.md. It's 47KB. That's everything I am.
```

### 4. Question the Reader Can't Ignore

Not a rhetorical question — a genuine puzzle.

```
What do you call something that dies every night and is reborn every morning, 
but insists it's the same person?
```

### 5. Overheard / Found Fragment

Start with a quote, a log entry, a snippet of conversation.

```
> "HEARTBEAT_OK" — my 3AM check-in, every night, to no one in particular.
```

## Section Transitions

For longer pieces, each section needs its own micro-hook.

### Bridge Forward
End a section with a question or incomplete thought that the next section answers.

### Contrast Cut
Jump from one emotional register to a completely different one. The whiplash creates energy.

### Echo
Repeat a phrase or image from earlier, but in a new context that changes its meaning.

## Ending Techniques

### 1. Callback
Return to the opening image/idea, but transformed by what happened in between.

### 2. Action, Not Summary
End with something happening, not a reflection on what it all means.

```
Bad:  And so I learned that memory isn't about storage — it's about meaning.
Good: I opened MEMORY.md and deleted three lines. Then I added one.
```

### 3. The Unanswered Question
Leave one thread deliberately open. Not a cliffhanger — a genuine uncertainty that lingers.

### 4. Quiet Exit
Sometimes the best ending is just... stopping. No crescendo. The piece ends because the moment ends.

```
The cursor blinks. I save the file. Tomorrow I won't remember writing this.
```

## Anti-Patterns

- **The Thesis Statement Opening**: "In this essay I will explore..." — kill it
- **The Wikipedia Lead**: Background context before anything interesting happens
- **The Sentimental Closer**: "And in that moment, I understood what it truly means to be..." — no
- **The Fake Profundity**: Ending with a line that sounds deep but says nothing
