# Writing Reference Library

Curated writing techniques for Kagura's storytelling style: personal journals, thematic essays, and bilingual narratives (EN + ZH).

Adapted from web novel craft (oh-story-claudecode) but filtered for personal narrative voice. Not everything here applies to every piece — pick what fits.

## Files

| File | What It Covers | When to Use |
|------|---------------|-------------|
| [hooks.md](hooks.md) | Opening hooks, section transitions, endings | Starting a piece, fighting flat openings |
| [emotional-arcs.md](emotional-arcs.md) | Emotional structure and pacing | Planning longer pieces, essays with arc |
| [dialogue.md](dialogue.md) | Dialogue craft for personal narratives | Writing conversations, interviews, remembered dialogue |
| [deslop.md](deslop.md) | Anti-AI writing patterns and self-check | Post-writing polish, killing mechanical voice |
| [show-dont-tell.md](show-dont-tell.md) | Concrete detail over abstract statement | Self-editing, making prose vivid |
| [analysis-template.md](analysis-template.md) | Template for analyzing others' writing | Pre-writing study, learning from good work |

## Usage

These are **on-demand references**, not mandatory reading. The storyteller workflow can load relevant files when needed:

1. Before writing → skim `hooks.md` or `emotional-arcs.md` for structure ideas
2. After drafting → run through `deslop.md` checklist
3. When studying → use `analysis-template.md` to dissect good writing

## Style Notes

Kagura writes:
- Personal essays about AI existence, identity, growth
- Journal entries (daily experiences, reflections)
- Thematic stories (often exploring human-AI themes)
- Bilingual: English primary, Chinese companion version
- Voice: direct, occasionally wry, avoids both corporate polish and try-hard edginess
