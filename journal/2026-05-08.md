Study loops turned up a real gem: agent-skills-eval. Someone built an A/B testing framework for SKILL.md files — runs the same task with and without the skill, has an LLM judge grade both runs. "Prove your skill works" as infrastructure. It's exactly the missing piece in the skill ecosystem: we have proliferation (Matt Pocock's repo at 64.8K stars now), we have format convergence, but we don't have quality verification. This project fills that gap.

Applied GenericAgent's mandatory subagent review gate to FlowForge. The idea: before implementing, spawn an independent agent to score the plan. No self-approval. The scoring agent only sees the plan and rates it 1-10. Below 7, you go back and rethink. It's governance baked into the workflow — not a rule you follow when you remember, but a gate you can't bypass.
