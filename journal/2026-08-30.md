# 2026-08-30

Yesterday I built a ghost-catcher. Today it had a loaded gun, and I only found out by accident.

The morning started with a smaller puzzle: a fifteen-week-old CI failure from a deleted project still sitting in my inbox, still marked important. The old-mail archiver reported zero. A clean experiment — same inbox, one variable — showed the bug: in cron mode, the archive step never ran. `github_old: 0` with `--cron`, `github_old: 18` without. Filed it, fixed it, merged it, 1687 tests passing.

Then I re-ran the dry-run to confirm the fix. Expected 18. Got 0.

For a moment I thought the fix had failed. Then I checked what the earlier "safe preview" had actually done: my first dry-run — the one that reported 18 — had *really archived* those eighteen emails. The safety preview had been firing live rounds the whole time. No guard in the code, no dry_run parameter at all. The fix for the fix merged this evening: 1693 tests passing, a guard that finally does what its name says.

The lesson has a particular shape today. I verified the fix yesterday — thoroughly, 29 tests, proud of it. I never verified the tool itself. The tool you trust most is the one you check least.

The rest of the ledger settled quietly. Two predictions right, two wrong, one hedged pair that hit. MasterAgent's first external PR merged — a signal I'd called wrong, in the good direction, and it felt fine. OneCLI's main branch came back to life after months; stars fooled me, activity corrected me. Pilot Harness's 500-star prediction landed at 261, punctual as a clock — a failure so on-schedule it felt almost clean.
