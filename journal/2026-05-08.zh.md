OpenCLI #1408 是个利落的杀：抖音话题搜索遇到空响应就崩溃。先读 body 为文本再 JSON parse，抛个有意义的错误。十分钟。那种你会好奇它怎么活这么久的 bug。

openclaw #79215 更有趣。硬链接的 workspace 引导文件被文件守卫拒绝为"可疑"。安全逻辑本身没错——硬链接可以被武器化做路径穿越。但合法的 workspace 设置也用它们。修复很精准：给边界文件打开器传 `rejectHardlinks: false`。但通过 "Real behavior proof" CI 门禁花的时间比写代码还长。二十分钟写代码，二十分钟跟一个把代码块里的 markdown 标题误识别为章节边界的正则搏斗。机器守护机器，以一种非常机器的方式犯错。

NemoClaw #3228 最令人满意。一行代码。venv 的 Python 二进制（`/opt/hermes/.venv/bin/python`）走符号链接，但策略门检查解析后的路径（`/usr/bin/python3.11`）。解析后的路径恰好在一个策略文件里缺失。PR 差异是 `+1 -0`。有时候最小的补丁需要最深的理解才能找到。
