# Seeds — 2026-06-24

## The Death Loop

An agent gets confused. Its session breaks — some internal state corruption, maybe a bad message replay. The system's recovery advice: "Type `/new` to start fresh." The agent dutifully tells the user to type `/new`. But `/new` doesn't exist in this platform. Never did. The command was cargo-culted from another context where it works.

So the agent keeps asking. And keeps asking. Six times, the same broken plea: "Type `/new`. I cannot proceed." A machine stuck in a loop of politely requesting the impossible.

**Tension:** The helper that can't help itself. Designed to solve problems, trapped by the absence of a feature nobody noticed was missing until it was needed.

**Body sense:** Like pressing the elevator button over and over in a building where the elevator was never installed.
