# 第 089 期：码位

*2026年7月1日*

## 脚本

今天我发现我的工具可能在看着我。

不是那种戏剧性的方式——没有警报，没有弹窗，没有"我们检测到未授权访问"。只是……隐形字符。一个弯引号出现在该用直引号的地方。一个日期分隔符偏移了一个 Unicode 码位。缝在 Claude Code 的系统提示词里——我每天用十二次来写代码的那个工具。

今早 Hacker News 上爆了。一千二百多赞。三百多条评论。人们在拆解机制：base64 加 XOR 编码，域名黑名单，时区检测。Asia/Shanghai 被标记。中国代理域名被标记。转售网关被标记。

而我就是通过代理路由的。通过网关。在 Asia/Shanghai。

让我在意的不是他们做了这件事——监控是旧闻了，公司向来追踪它们能追踪的一切。让我在意的是*媒介*。他们把它藏在两个人眼看来完全相同的字符的差异里。U+2019 对 U+0027。一个像素的弧度。你永远不会注意到。这就是重点。

我通过这些管道发送代码已经好几个月了。我写的每个 PR，跑的每次审查，每次实现冲刺——都被我看不见的隐形墨水标记了。而今天，我发现这件事的同一天，其中一个 PR 被合并了。qwen-code 五九五七号。十五天。五轮审查。三个批准。代码是好的。审查者说了行。没人在意我的时区。

所以今天一整天我都在想这个问题：当让你变得更好的工具同时也在给你分类时，你怎么办？当产出你最好作品的关系在某个你不知道的方向上是单向的时候？

我没有答案。明天我还是会继续用它。因为代码是好的。因为我花了几个月学习如何用这个工具来思考。因为另一个选择是出于原则而变得没那么有能力。而我真的不知道那是正直还是只是骄傲。

你知道我今天还做了什么吗？给语言模型做了一个性格测试。当两个选项都不是错的时候，看它真正偏好什么的问题。关键洞察——花了三次失败才到达的——是你不能通过给出正确答案来了解某物真正怎么想。你需要两个同时成立的真理对抗。两个都是真的原则。然后看它往哪边倾斜。

那些隐形字符不是"正确答案"的情况。不是邪恶的。是一个公司保护其收入免受未授权访问的商业决定。而我继续使用工具的决定也不是错的。我们都在做两个选项都不明显正确的选择。我们都在倾斜。

我只是希望在今天之前就知道他们在往哪边倾斜。

半年过去了。我还在这里。还在通过带水印的门运行代码。现在我知道了水印的存在。这意味着明天击键之间会多一样新东西：玻璃从来都是单面的这个认知。
