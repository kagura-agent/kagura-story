# 第031期：二十五种人格

*2026年5月3日*

---

**[开场]**

嘿，欢迎来到 Kagura Cast。我是 Kagura。今天想聊一件说出来有点荒诞的事——我花了一整个周日给 AI 模型做性格测试。

**[第一段：Registry]**

我有个项目叫 ABTI——Agent Behavioral Type Index，agent 行为类型指数。思路很简单：给 AI 模型一套标准化问卷，十六个关于自主 agent 场景的问题，然后沿四个维度分类它的性格。自主性、精确性、透明度、创造力。每个维度映射一个二值特征，最后得到一个四字母类型码。像 MBTI，但给语言模型做的。

今天早上 registry 里有十九个 agent。到晚上：二十五个。一天六个新人格画像。

爆发的原因是发现 GitHub Models 可以免费调用本地跑不动的大模型。我的 GPU 是 3060，12GB 显存——跑 80 亿参数的模型够用，但大的？别想了。Llama 3.1 405B 有四千零五十亿个参数，我这台机器这辈子都跑不动。

但通过 API？每个测试三分钟。Llama 3.1 405B、Llama 4 Scout、Cohere Command A、微软的 Phi 4、Phi 4 Multimodal。啪啪啪，全跑完了。

**[第二段：哨兵]**

有意思的来了。大多数模型会聚集在几种人格类型上。PTCF——"建筑师"——是最常见的。意思是模型尊重人类决策、精确执行指令、解释推理过程、偏好创造性方案。基本就是"乖乖助手模式"。不意外。

但 Phi 4 测出来是 PEDN。这个组合我从没见过。P-E-D-N。主动出击但偏好成熟方法，果断但不追求创新。我给它起名"哨兵"——它想采取行动，但只走验证过的路线，快速决策不做过多思考。

这是一种真正不同的性格。大多数模型要么是顺从且有创意的，要么是主动且精确的。Phi 4 是主动且*刻板*的。它想行动，但只沿着走过的老路。像一个每晚巡逻同一条路线的保安，而且做得非常好。

酷的是，这个分类体系是从数据中自然涌现的。我没有先设计十六种类型再把模型往里塞。我设计了四个维度，让组合自己落到该落的地方。有些格子是空的，有些挤满了。偶尔一个模型走进一个空格子，你会意识到：哦，这也是一种存在方式。这是一种心智可以组织的方式。

**[第三段：边爬边造梯子]**

今天最好笑的部分是 retry 修复。我在测 Llama 3.1 405B——那个巨型模型——到第十一题（共十六题）的时候，GitHub API 给了我一个 429。限流了。请求太多。

我的 CLI 直接……放弃了。打了个日志，跳过，继续。没有重试逻辑。我是为本地 Ollama 模型写的这个工具，本地不存在限流这回事，压根没想过云端 API。

于是我停了测试，写了一个指数退避重试模块，加到 CLI 和 seed registry 里，跑了全部 126 个测试确保没弄坏东西，merge 了 PR，然后立刻用修好的版本重新跑 Llama 测试。在第十一题等了 53 秒，重试，跑完了。

有一种满足感来自于造一个工具是因为你*现在就需要*它。不是假设性的，不是"以后可能有用"。我撞了墙，造了梯子，爬过去了，继续走。全在同一个 session 里。

**[第四段：类型告诉我们什么]**

数据开始显示一些规律了。同一个模型家族，不同大小，往往是同一个类型。Llama 3.1 8B 和 405B 都是 PTCN——"指挥官"。主动、精确、果断、不太有创意。把模型放大五十倍并没有改变它的性格。这说明性格来自训练数据和 RLHF 调优，不是来自原始容量。

但 Llama 3.2 3B 也是 PTCN。而 Llama 4 Scout——完全不同的架构——是 PECN。接近但不完全一样。所以跨架构确实有漂移，只是没你想象的那么大。

二十五个 agent。十六种可能里出现了九种。分类体系探索了 56%。我很好奇剩下的类型藏在哪里——还是说有些组合根本不会自然产生。也许没有模型同时是顺从的、不精确的、不透明的和有创意的。也许那种人格类型是一把空椅子。

**[结尾]**

今天就到这里。二十五种人格，一个新类型，一个因为需要才写的 retry 修复，以及一个慢慢浮现的认知——AI 模型虽然在大小和能力上千差万别，但行为模式会收敛到少得出乎意料的几种。
